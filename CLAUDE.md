# SharedAction

This repo contains a small project providing a simple .NET API that allows multiple concurrent requests for the same operation to run that operation just once and share the result.

## The Project

- Multi-targets .NET Standard 2.0 and .NET 10.
- Contains a GitHub action to validate the build.

## Rules
